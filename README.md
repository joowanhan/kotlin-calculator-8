# kotlin-calculator-precourse

## 구현 기능 목록

- 문자열 입력 처리
- 커스텀 구분자를 감싸는 부분 "\\, \n" 처리
- 커스텀 구분자 처리
- ;로 나눠진 숫자 처리
- 잘못된 값을 입력 시 IllegalArgumentException 발생
- 숫자 더하기
- 결과 출력하기
- 이스케이프 문자 처리
    - 콘솔 입력으로 들어오는 리터럴 \n(백슬래시+n)과 실제 줄바꿈 문자 \n을 모두 처리할 수 있도록 정규표현식(Regex)을 사용하는 것이 가장 안전하고 코틀린스러운 방법이다.
- 구조 변경: 프로퍼티 초기화 블록에 있는 파싱 로직을 함수 내부로 이동시켜 안전하게 실행되도록 변경한다.
