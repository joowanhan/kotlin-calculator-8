# kotlin-calculator-precourse
##  기능 목록

### 덧셈 계산기 입출력 구현
* "덧셈할 문자열을 입력해 주세요." 문구 출력
* 사용자로부터 문자열 입력 받기
* 계산 결과 출력 (ex. "결과 : 6")

### 빈 문자열 또는 null 처리 기능 구현
* 입력 값이 null 또는 빈 공백 문자일 경우 0을 반환한다.

### 기본 구분자(쉼표, 콜론)로 분리한 숫자들의 합 계산
* 입력 문자열을 쉼표(,) 또는 콜론(:)을 기준으로 분리한다.
* 분리된 각 문자를 숫자로 변환하여 합산한다.

### 커스텀 구분자로 분리한 숫자들의 합 계산
* 입력 문자열이 "//"와 "\n" 사이의 문자를 포함하는 경우, 해당 문자를 커스텀 구분자로 사용한다.
* 커스텀 구분자를 기준으로 문자열을 분리하고 합산한다.

### 예외 처리 기능 구현
* 분리된 문자가 숫자가 아닐 경우 IllegalArgumentException을 발생시킨다.
* 분리된 숫자가 음수일 경우 IllegalArgumentException을 발생시킨다.
